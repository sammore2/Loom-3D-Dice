# Atribuição

Este addon é um port third-party para LoomVTT do **Dice So Nice! v3.0.0-final**.

- **Upstream**: https://github.com/MSanteler/foundryvtt-dice-so-nice
  (fork para dev custom do projeto original de Simone e JDW)
- **Licença declarada pelo upstream**: Creative Commons Attribution 4.0
  International (CC-BY-4.0) — ver seção "License" do README do upstream.
- **Autores originais**: Simone, JDW (e contribuidores listados no upstream).
- **Base técnica verificada**: o diretório `module/` do upstream é idêntico
  (byte a byte) à base usada neste port — referência pristine em
  `E:\dice-so-nice-github` (não modificar; só leitura).

O que foi adaptado para o LoomVTT (sem alterar arte do motor):
`dsn/*` , `client.js` (entry nativa:
LoomHooks/settings/BaseWindow), `addon.json` (manifest), `styles/`.
Motor 3D, texturas, sons e geometrias: créditos integrais ao upstream.
